# LOOP - Proyecto Web

Este proyecto fue desarrollado por **Luis Díaz**.

## 🚀 Descripción

LOOP es un sitio web con menú fijo, diseño responsivo y secciones dinámicas.  
Incluye integración de **HTML**, **CSS** y **JavaScript** en archivos separados para mantener la organización del proyecto.

## 📂 Archivos principales

- `index.html` → Página principal
- `style.css` → Estilos CSS
- `script.js` → Funcionalidades (ej: redirección de Login)
